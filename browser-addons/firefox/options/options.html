TrelloHelper

A Firefox add-on that adds small, useful features to help with your day-to-day work on Trello. - Open-source, lightweight and personally tested.

Trello Link Redirect

Automatically send supported Trello card and board links to the Trello desktop app instead of opening them in Firefox. The desktop app must be installed on this PC for this feature to work.

MAIN FEATURE CONTROL

Automatic redirect

This is the master switch for the redirect rules below.

Enabled

Requires the Trello desktop app to be installed on this PC.

Rules by page type

Rules apply to new navigations to trello.com and www.trello.com.

Support for other pages depends on whether the installed Trello app accepts their URL format.

Close the Firefox tab

Control whether the original tab closes after the desktop app is launched.

Enabled

Changes are saved automatically.

Note: Link redirection preserves the current conversion approach by replacing https:// with trello://. Firefox usually asks for permission the first time you open an external Trello link.
